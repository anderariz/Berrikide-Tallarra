# BerriKide Taller

Prototipo de interfaz para operarios, pensado para tablet en horizontal.

## Uso
Abre index.html en un navegador. No requiere instalación ni compilación.

## Incluye
- Dos procesos simultáneos de ejemplo: prensa y roscadora.
- Cambio entre tareas conservando el paso.
- Contadores de intervención y máquina.
- Verificación simulada de ubicaciones y máquina.
- Registro de producción, devolución a almacén y bloqueo con motivo.

## Alcance
Es una demostración con datos de ejemplo. La cámara, los QR, los avisos de máquina y Businessmap no están conectados. Los datos se reinician al recargar.

## Subir a GitHub
1. Descomprime el ZIP.
2. Abre anderariz/berrikide-taller en GitHub.
3. Usa Add file > Upload files (en móvil puede estar en el menú de tres puntos junto a Code).
4. Arrastra index.html y README.md a la raíz del repositorio.
5. Confirma con Commit changes.

## Publicación
Subir los archivos guarda el código, pero no publica una web. Si tu cuenta permite GitHub Pages para este repositorio, configura Settings > Pages > Deploy from a branch > main > /(root). Si no aparece disponible para el repositorio privado, conserva su privacidad y usa otro alojamiento o un plan compatible.
